# AI-Powered-Email-Automation

## Overview
This is a no-code AI-powered email automation system designed for e-commerce customer support. It automatically responds to customer emails using AI and a knowledge base.

## Features
- Automated email replies
- AI-generated responses
- Order support handling
- Shipping & refund queries
- No-code workflow automation

## Tools Used

- Zapier (Workflow Automation)
- AI by Zapier (AI Response Generation)
- Gmail (Email Sending & Receiving)
- Google Docs (Knowledge Base / Content Storage)

## How it Works
1. Customer sends email
2. Workflow captures email
3. AI reads message
4. Knowledge base used for answer
5. Auto reply sent to customer

## Project Purpose
This project is built for portfolio and learning purpose to demonstrate AI automation skills.
